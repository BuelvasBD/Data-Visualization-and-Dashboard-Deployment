#  University Student Dashboard (Data Visualization & Deployment)

This project is an interactive **Streamlit dashboard** developed for the activity **"Data Visualization and Dashboard Deployment"** (Data Mining course - Universidad de la Costa).

The goal of this dashboard is to analyze and visualize key indicators related to **student admissions, enrollment, retention, and satisfaction** across academic years, terms, and departments.

---

##  Project Objectives

The dashboard helps the university to:

- Explore student application and enrollment behavior across years.
- Monitor retention rates and satisfaction trends.
- Compare academic terms (Spring vs Fall).
- Identify enrollment distribution by department.
- Support decision-making through data-driven insights.

---

##  Dataset Information

The dataset used is:

📄 `university_student_data.csv`

---

## 🚀 Features of the Dashboard

Interactive filters (Year and Term)  
KPI Metrics:
- Total Applications
- Total Admitted
- Total Enrolled
- Average Retention Rate
- Average Satisfaction Score  

 Visualizations:
-  Line chart: Retention trends over time
-  Bar chart: Satisfaction score by year
-  Pie chart: Enrollment distribution by department

 Dynamic update of all metrics and charts according to the selected filters.
